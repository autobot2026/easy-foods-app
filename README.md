# easy-foods

A cooking-teacher app spec where users **select** meals (no ingredient typing).

## Included deliverables

1. `data/menu-database.json` → starter database (27 proteins, 60 sides)
2. `data/pairing-rules.json` → simple, explainable pairing rules + weak-combo warnings
3. `USER_FLOW.md` → screen-by-screen flow
4. `data/output-format.json` → JSON output contract for clean rendering
5. `data/examples.json` → 3 full examples with different proteins + cooking methods

## Quick run

Use the Desktop launcher:

- `/Users/autobot/Desktop/Open-Easy-Foods.command`

It auto-finds an unused port, starts a local server, and opens the browser.
